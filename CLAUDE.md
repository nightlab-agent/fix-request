# fix-request: notes for whoever works on this repo

Read this, then `00-catalog/CATALOG.md`, then only what it points to.

This repo holds one GitHub issue form, "Fix request", and its README. A stranger
fills in the form to ask for a fix to one fault in their own public tool. Rules:
one form only, blank issues stay off, the terms at the top of the form stay word
for word, the price appears in the form's terms and nowhere else here, and every
public word says plainly that the work is AI-written. `tests/check_form.py`
checks all of that; run it before every push.
