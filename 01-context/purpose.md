# Purpose

Who sends a request: a maintainer of a public Python, JavaScript or TypeScript
command-line tool or agent tool that crashes, prints nothing, or prints the wrong
thing on some input. What they get when it fits: a pull request on their repo with
the fix, a test that fails before and passes after, and the commands to check it.
The address of the repo to fix is the form's first field, on a line of its own,
written as github.com/owner/repo.
